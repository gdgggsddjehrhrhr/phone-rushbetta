PHONE RUSH — проект для сборки Android APK через GitHub Actions с телефона

ВАЖНО: APK заранее не собран. GitHub соберёт его в облаке.

Как собрать только с телефона:
1. Скачай ZIP и распакуй его приложением для архивов.
2. Открой https://github.com и войди или создай аккаунт.
3. Нажми + -> New repository. Название: phone-rush. Выбери Public (или Private, если удобнее) и создай репозиторий.
4. Загрузи ВСЕ файлы и папки из распакованного проекта в корень репозитория. Обязательно должна быть папка .github/workflows с файлом build-apk.yml. Если файловый менеджер скрывает папки с точкой, включи показ скрытых файлов.
5. Открой вкладку Actions в репозитории. Если GitHub попросит разрешить Actions, подтверди.
6. Выбери workflow «Build PHONE RUSH APK» -> Run workflow -> Run workflow.
7. Дождись зелёной галочки. Открой завершившийся запуск и внизу страницы найди Artifacts.
8. Скачай phone-rush-debug-apk.zip и распакуй его. Внутри будет app-debug.apk.
9. Открой APK на телефоне и разреши установку из этого источника, если Android попросит.

Если загрузка через браузер неудобна: в репозитории нажми Add file -> Upload files и выбери все файлы проекта. Не загружай ZIP как единственный файл — нужно загрузить содержимое архива.

Если сборка упадёт, открой красный запуск в Actions, скопируй последние строки ошибки и пришли их сюда. Не публикуй пароли, токены или секретные ключи.
